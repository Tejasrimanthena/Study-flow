StudyFlow – SaaS Landing Page



About the Project



StudyFlow is a responsive SaaS landing page designed to help students manage their learning and study activities.



Features



\- Responsive navigation bar

\- Hero section with call-to-action buttons

\- Features section

\- About section

\- Pricing plans

\- Contact section

\- Mobile-friendly design



Technologies Used



\- HTML

\- CSS

\- JavaScript



How to Run



1\. Download or clone the project.

2\. Open the project folder.

3\. Double-click "index.html".

4\. The website will open in your browser.
